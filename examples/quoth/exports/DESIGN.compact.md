# Halderworks Instrument, quoth brand - DESIGN.md

Generated by `tools/export.py` from `tokens.json`. Do not hand-edit.

A house design system: one token set, 2 themes, two densities. 33 colour tokens per theme, all pairs certified at WCAG AA for text and 3:1 for non-text indicators. Neutral ground, one accent hue, colour spent only where a state is reported.

## Rules that are not negotiable

1. Never write a literal colour, size, radius, duration, breakpoint or z-index. A value the system lacks is a gap to report, not a number to invent.
2. Put ink only on a ground the permission table allows. Never re-derive a ratio by eye.
3. The primary action is hw-ink and carries no hue. There is exactly one per screen.
4. The accent has four jobs: a link, a selected row, a live state, the focus ring. A screen with no state on it has no hue on it.
5. Every state carries a word, never a colour alone.
6. No gradient behind text, no backdrop-filter, no shadow on anything that cannot be dismissed. A patterned ground carries only ink certified against its own worst pixel.
7. Uppercase exists at one step, micro, for a column head or an eyebrow.
8. Every column of figures takes tabular-nums.
9. Left-aligned by default. Centre only a single-element empty state or a dialog action row.
10. The focus ring is never removed.
11. No invented quotes, logos, metrics or placeholder data presented as real.
